# MTG資料を文書形式へ変更（仕様v1.3）

日付：2026-11-04。ブランチ：docs/mtg-document-format。

## 目的と変更

MTG資料をGoogleドキュメントのように読める、編集可能なMTGガイドに変更する。PPTX・スライド・枚数の要件を外し、原稿をMarkdownでGit管理して、Googleドキュメントにも転記できる構成にした。

背景・モデル解説・環境準備・操作手順・実際の結果と比較・考察・参考文献を収録する。90分進行表、実演台本、チートシート、まとめテンプレートは本文内の節または別文書とする。ローカル閲覧の要件も維持する。

確定仕様をv1.3へ更新し、AGENTS.md、README.md、HANDOFF.md、CODEX_START_PROMPT.mdの現在の要件を揃えた。v1.2のレビュー記録は過去の記録として保持する。

## 確認と制限

- 現行5文書と変更記録の資料要件・v1.3表記・内部リンク6件を照合し、問題なし。旧PPTX要件は廃止の説明と過去の記録にのみ残す。
- 文書だけの変更のため、コードの単体テスト・ruff・CLI実行は対象外。差分の空白とコードブロックの閉じ忘れも確認し、問題なし。
- MTGガイド本文・Googleドキュメントは未作成。モデル実装・重み取得・実機検証・性能測定も未実施。

## 次の作業

実装と実機検証で得た結果を使い、docs/mtg-materialsの工程でMTGガイドを作成する。
