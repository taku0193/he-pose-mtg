# MTG用文書と3素材（2026-11-05）

90分ガイドに進行表、実演台本、SSH接続からMacで動画を開く手順、実測の読み方、障害時の切替をまとめました。コマンド表、観察と仮説の記入欄、参加者3人の受入記録、環境・重み・文献の一覧を添えています。編集原稿は `docs/mtg/` にあります。

basicとmultiはCommonsの素材から実際の動作区間を切り出しました。fastは前回の15秒の検証素材と同一です。各素材の作者・元ファイル・ライセンス・変換条件・SHA256を記録しています。録画、比較動画、編集用DOCX、オフライン配布セットはローカルに保存しています。 [素材の出典](../mtg/sample-sources.md)

abertの割当RTX 3090でbasicとmultiを新たに3モデルで順次計測し、各300枚の比較動画を作成しました。fastの375枚は同一入力の既存結果を再利用しました。3素材すべてで共通100件を計測し、元フレーム番号・FPS・TARの未推定4枚を照合しました。Mac実機と参加者3人の受入は記録欄を用意し、判定を未実施としています。 [実行記録](../experiments/mtg-abert-2026-11-05.json) · [受入記録](../mtg/acceptance.md)

レビュー後、計測成功時だけ比較と出力先の表示に進むよう手順を更新しました。GPUは参加者ごとの設定を使い、ライブの終了経路は受入表で分けています。更新した手順をガイド、コマンド表、オフライン配布版へ反映しました。
