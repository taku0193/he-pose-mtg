# 3モデルの姿勢推定比較

2026年11月5日にabertで保存した、YOLO26n-Pose・DETRPose-N・TAR-ViTPose Baseの3素材分の推定結果を集計した。今回の条件では **YOLO26が3素材とも最速**。速い動きで人物を1人も出力しないフレームはDETRPoseが最少だった。正解座標がないため、姿勢推定の精度順位は未評価。

## 録画処理速度

| 素材 | YOLO26n-Pose | DETRPose-N | TAR-ViTPose Base |
| --- | ---: | ---: | ---: |
| basic | **178.69** | 68.56 | 16.78 |
| fast | **178.00** | 66.51 | 20.36 |
| multi | **163.02** | 65.27 | 5.80 |

値は録画処理FPS。入力は640×480、25 FPS。RTX 3090を1台使い、PyTorch・FP32・batch=1で別プロセスを順に実行した。各素材・各モデル1回で、共通の元フレーム2〜21でウォームアップし、22〜121の100枚を計測した。フレーム番号は0始まり。

FPSは100枚を処理した区間の実時間から算出し、復号、推定、描画、フレーム単位の書き込みを含む。TARではYOLO11xによる人物検出と切り出しも含む。録画の処理能力のため、MacへのSSH転送や表示のFPSは含まない。

[集計CSV](metrics.csv)にはモデルのforwardのp50・p95、推論時間の有効件数、PyTorchが記録した各プロセスのGPUメモリ割り当てのピークを収録した。TAR本体の推論時間は、人物を検出したフレームを対象に、同じフレーム内で人物ごとのforwardを合算した値。たとえば `fast` は100枚のうち77枚が有効で、p50は35.84 ms。メモリの値は、GPU全体の使用量とは集計範囲が異なる。

## 速い動きで人物が出なかったフレーム

`fast` は375枚。全モデルが推定を実行した元フレーム2〜372を対象に、各モデルの出力人数を数えた。TARは中心フレームの前後2枚ずつを使うため、先頭と末尾の各2枚は未推定として比較から除いた。

| モデル | 人物0件のフレーム | 連続で0件になった最長 |
| --- | ---: | ---: |
| YOLO26n-Pose | 15 / 371 | 3枚（0.12秒分） |
| DETRPose-N | **6 / 371** | 2枚（0.08秒分） |
| TAR-ViTPose Base | 55 / 371 | 13枚（0.52秒分） |

3.80秒（95番）では、床に手をついた人の骨格をDETRPoseだけが出力した。4.20秒（105番）ではYOLO26とTARが出力し、DETRPoseは0件だった。14.20秒（355番）ではDETRPoseが画面左側にも骨格を出力した。モデルごとに検出閾値が異なり、出力件数だけでは、主役を捉えた割合や誤検出の数は分からない。

## 二人が重なったとき

`multi` の5.20秒（130番）では、TARが手前の二人と奥の一人に骨格を出した。5.40秒（135番）では、TARの2件のうち1件が画面奥にあり、手前では3モデルとも1人分だった。6.00秒（150番）では3モデルとも手前の二人に骨格を出した。これらは選んだフレームの観察で、動画全体で同じ人物を追えたかは未評価。

## 基本動作の関節位置の違い

`basic` で3モデルが1人ずつ出力し、同じ名前の関節座標が3モデルすべてで得られた場合を集計した。元画像上の2次元距離の中央値をモデルの組み合わせごとに計算し、左右は合算した。

| 関節 | 左右の有効点数 | YOLO–DETR | YOLO–TAR | DETR–TAR |
| --- | ---: | ---: | ---: | ---: |
| 肩 | 590 | 2.8 px | 4.7 px | 4.4 px |
| 肘 | 562 | 3.8 px | 4.0 px | 4.7 px |
| 手首 | 553 | 3.3 px | 4.9 px | 4.3 px |

[関節の集計CSV](joint-agreement.csv)。ここで測ったのはモデル同士の座標の差。どのモデルが正しいかを判断するには、同じフレームに正解座標を付けて比較する必要がある。

## MTGでの使い分け

- **YOLO26n-Pose**はライブ実演に使う。今回の3素材で録画処理が最も速く、現行CLIでMacからの遠隔ライブに対応している。
- **DETRPose-N**は速い動きの録画で、YOLO26と骨格が出なかった場面を見比べる。
- **TAR-ViTPose Base**は前後の画像を使う手法として、複数人が交差する場面を録画で確認する。
